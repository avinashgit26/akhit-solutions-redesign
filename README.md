# AKH IT Solutions redesign

This public repository contains the redesigned static website in `site/` and 22 full-page desktop design references in `design-references/`.

## GitHub Pages

The Pages workflow deploys `site/` whenever a commit is pushed to `main`. After the first successful deployment, open the repository's **Settings → Pages** page for the live URL.

Once deployment completes, the site URL will be <https://avinashgit26.github.io/akhit-solutions-redesign/>.

## Preview locally

Open `site/index.html` in a browser. For best results, serve the `site/` folder with a local static file server.

## Forms

GitHub Pages cannot process job applications or host the existing form backend. Use the forms on the live AKH IT Solutions website for submissions: [Contact](https://akhitsolutions.com/contact-us.html) and [Careers](https://akhitsolutions.com/careers.html).

The design-reference folder contains a page mapping and the full-page PNGs.
